# Drinks Ordering System (Python OOP Practice)

I built this simple terminal app to get hands-on experience with Object-Oriented Programming (OOP) in Python. It simulates a basic drinks ordering system where you can pick drinks, add them to a cart, check your total, and go through a simulated checkout.

## What it does

* Displays a simple menu with options for Coca-Cola, Fanta, and Sprite.
* Keeps track of added items and running costs inside a `Cart` object.
* Let's you view your current cart and calculates the total price at checkout.
* Catches invalid menu entries using basic error handling.

## What I learned building this

* How to structure classes (`Drink` and `Cart`) and instantiate objects.
* Passing object attributes like price and name into a cart manager.
* Handling control flow with `while` loops, `if/elif` statements, and `try/except` blocks.
